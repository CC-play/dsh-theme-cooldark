|---|---|---|---|---|
| `--dsw-specific-sidebar-fill` | `var(--dsw-static-neutral-bluish-900)` | `var(--dsw-static-neutral-bluish-50)` | ✅ | 侧栏底色 |
| `--dsw-specific-bubble` | `var(--dsw-static-neutral-bluish-850)` | `var(--dsw-static-deepseek-50)` | ✅ `rgba(0,0,255,.1)` | 用户 / steering / `/goal` 气泡底 |

气泡的**描边与反色墨色不在 token 层**，靠注入样式实现，见 README「聊天气泡」。
